# Google Apps Script: экспорт метаданных Drive

`ExportDriveMetadata.gs` обходит выбранную папку Drive и все вложенные папки,
создаёт лист `Drive metadata export` и записывает по каждой работе:

- путь и имя файла;
- file ID и прямую ссылку;
- размер и дату изменения;
- **владельца** (`owner_email`);
- **последнего редактора** (`last_editor_email`);
- безопасно выбранный `suggested_student_email`.

Это решает случай файлов типа `1 страница.jpg` или случайных длинных имён: имя
файла не используется как идентификатор студента, пока не найдется email.

## Быстрый запуск

1. Откройте <https://script.google.com> → **New project**.
2. Вставьте содержимое `ExportDriveMetadata.gs` в файл `Code.gs`.
3. Нажмите **Services** → **+** → добавьте **Drive API**. Это обязательно:
   встроенный `DriveApp` не предоставляет нужные email владельца и последнего
   редактора для пакетного экспорта.
4. Скопируйте ID папки из ссылки Drive. В ссылке
   `https://drive.google.com/drive/folders/ABC...` ID — это `ABC...`.
5. Вставьте ID в `ROOT_FOLDER_ID` и перечислите все staff-email в `STAFF_EMAILS`.
6. Выберите функцию `exportDriveMetadata` в верхнем списке и нажмите **Run**.
7. При первом запуске подтвердите доступ. Для standalone-проекта скрипт сам
   создаст таблицу; её ссылку можно взять в **Execution log**. В привязанной
   к таблице версии появится новый лист `Drive metadata export`.

## Как читать таблицу

- Используйте в первую очередь `suggested_student_email`, когда `email_source = owner`.
- Если `email_source = last_editor_fallback`, сверяйте вручную: это запасной
  вариант, а не доказательство авторства.
- Если `owner_is_staff = yes`, owner не будет выбран как студент. Добавьте все
  известные email ассистентов в `STAFF_EMAILS` до запуска.
- Пустой `suggested_student_email` означает, что по метаданным нельзя безопасно
  определить студента. Оставьте файл в ручной очереди.

## Перенос в приложение

1. Сопоставьте `suggested_student_email` с реестром Gmail.
2. В приложении откройте «Работы» → ручная идентификация и внесите email владельца.
3. Если email уже есть в реестре, файл можно назначить студенту. Если email новый,
   сначала добавьте студента в реестр.
4. Не назначайте файл только по совпадению имени, если есть конфликт с email.
