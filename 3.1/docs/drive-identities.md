# Сквозная идентификация работ

SQLite хранит подтверждённую связь `Drive permissionId → student_id → email/ФИО`
в `drive_accounts`. Она общая для всех ДЗ. Подтверждение записывается в аудит;
попытка перепривязать тот же аккаунт другому студенту блокируется.

Drive может не выдавать email; `displayName` не является email и не доказывает
личность. [Описание User в Drive API](https://developers.google.com/workspace/drive/api/reference/rest/v2/User).
Подтверждайте связь по явному указанию преподавателя или проверенным метаданным.
ФИО внутри работы — дополнительная ручная сверка, не автоматический OCR-привязчик.

Из корня проекта:

```bash
python3 scripts/drive_identity.py bind --permission-id 'ACCOUNT_ID' --email 'student@example.com' --evidence 'Источник подтверждения'
python3 scripts/drive_identity.py import --homework 3 --folder '/absolute/path/to/files' --manifest '/absolute/path/to/manifest.json'
```

Манифест — JSON-массив, одна запись на локальный файл:

```json
[
  {
    "local_name": "homework.pdf",
    "file_id": "DRIVE_FILE_ID",
    "sha256": "SHA256_OF_DOWNLOADED_FILE",
    "owner_email": "",
    "owner_permission_id": "",
    "last_editor_email": "",
    "last_editor_permission_id": "ACCOUNT_ID"
  }
]
```

Связывайте скачанный файл с метаданными по Drive file ID и проверяйте SHA256;
одно совпадение названия недостаточно. Не смешивайте владельца и редактора.
Аккаунты сотрудников исключаются; конфликт email, подтверждённого аккаунта или
ФИО в имени файла отправляет работу на ручную идентификацию. Неизвестный аккаунт
без email и ФИО также не угадывается. ID передавайте строкой, не числом.

Обновлённый `scripts/google-apps-script/ExportDriveMetadata.gs` (Drive API v2)
выгружает оба permissionId отдельными текстовыми колонками. Чтобы получить их
в следующих выгрузках, вставьте обновлённый код в свой Apps Script. Локальная
правка репозитория не обновляет облачный скрипт автоматически.

Обычный импорт папки в интерфейсе по-прежнему сопоставляет имена файлов.
Для сквозной привязки агент использует CLI выше либо передаёт `drive_metadata`
в `POST /api/homeworks/<id>/import`: словарь `local_name → запись манифеста`.
Данные Drive не находятся внутри скачанного PDF автоматически.

Повторный импорт не заменяет файл у существующего черновика или утверждения,
даже если новый формат приоритетнее. Замена требует отдельного осознанного
решения преподавателя и новой проверки. Импорт не утверждает баллы и ничего
не записывает в Classroom или ведомость.
