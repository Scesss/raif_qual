# Матрица доступов

| Роль | Репозиторий | Локальная `data/` | Classroom/Drive | Официальная ведомость |
|---|---|---|---|---|
| Владелец курса | Admin | Полный доступ | Преподавательский доступ | Вручную |
| Второй проверяющий | Write/Maintain | Только на своём компьютере | Только чтение или выданный курс | Вручную, по решению владельца |
| Codex/агент | Не нужен | Чтение материалов, запись черновиков | Нет | Нет |
| Студент | Нет | Нет | Только собственный Classroom | Нет |

## Правила

- Не добавляйте `data/` в GitHub даже в приватный репозиторий без отдельного согласия всех ответственных за персональные данные.
- Для второго проверяющего лучше передать зашифрованный архив рабочей базы, а не давать доступ к общей папке.
- Доступ к Google Drive выдаётся отдельно и не является частью этого приложения.
- Роль `Write` позволяет менять код, поэтому перед выдачей её убедитесь, что участник доверенный; для просмотра достаточно `Read`.
