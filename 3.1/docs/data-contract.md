# Данные и резервное копирование

## Ключевые сущности

- `students`: email, ФИО, алиасы, заметки преподавателя.
- `homeworks`: номер, дедлайн, ссылка Classroom, пути к условию, лекциям и эталону.
- `submissions`: оригинальное имя, локальный файл, email владельца, статус сопоставления.
- `reviews`: черновые/утверждённые баллы, комментарии, основания, сигналы и журнал.
- `audit_log`: кто и когда изменил значимую запись.

## Импорт

Файлы должны быть PDF, TeX, JPG, JPEG или PNG. Файлы копируются внутрь `data/submissions/hw-NN/`; исходная папка не изменяется. У одного студента выбирается один основной формат по приоритету TeX → PDF → изображение.

## Резервная копия

Копируйте всю `data/`, когда приложение остановлено. Для проверки восстановления распакуйте копию в отдельный клон и запустите его на другом порту только после изменения кода, если это понадобится. Не редактируйте SQLite вручную без копии.
