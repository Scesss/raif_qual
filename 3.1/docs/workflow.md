# Подробный рабочий процесс

## До дедлайна

- Завести студентов по Gmail из формы или Classroom.
- Добавить варианты ФИО и известные алиасы файлов.
- Создать карточку ДЗ и проверить пути к условию и лекциям.
- Авторское решение добавлять в TeX, если оно доступно; PDF использовать для визуальной проверки формул и разметки.

## После дедлайна

- Скачать работы вручную в одну локальную папку.
- Импортировать папку один раз; повторный импорт не должен затирать утверждённые решения.
- Разобрать `unmatched`, дубли и альтернативные форматы.
- Для файла без ФИО сверить email владельца в свойствах Drive. Игнорировать email ассистента, если он указан как редактор/получатель доступа.

## Проверка

Для каждого студента агент обязан:

1. Прочитать условие, лекции и эталонные материалы.
2. Разобрать каждый номер отдельно и выставить 0–4.
3. Написать наблюдаемое основание, страницу работы и при необходимости страницу эталона.
4. Отделить служебные вопросы от спокойного комментария студенту.
5. Сохранить только черновик.

Преподаватель вручную проверяет все спорные места и только затем утверждает запись.
