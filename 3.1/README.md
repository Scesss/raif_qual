# GradeAI

GradeAI — помощник преподавателя для проверки домашних заданий по любым предметам. Проверка строится на условии, материалах и критериях конкретного ДЗ.

Преподаватель добавляет условие, критерии и работы студентов, затем запускает проверку. Агент читает решения, проверяет задания и готовит черновик с баллами и комментариями. Рядом можно открыть оригинал работы и посмотреть, на чём основана каждая оценка. Окончательное решение остаётся за преподавателем.

Это локальное веб-приложение: оно запускается на компьютере и открывается в браузере. Во время проверки выбранные материалы передаются подключённой модели.

## Как проходит проверка

1. Преподаватель создаёт карточку ДЗ: добавляет условие, критерии, список заданий и шкалу баллов. При наличии можно приложить эталонное решение и материалы лекций.
2. Импортирует работы из локальной папки. Для автоматической проверки нужен один полный PDF на студента.
3. Выбирает одну или несколько работ и запускает агента. Работы проверяются по очереди.
4. Следит за журналом: какие страницы агент прочитал, какие инструменты вызвал и что получил в ответ.
5. Открывает черновик рядом с работой, сверяет обоснования, при необходимости исправляет и утверждает результат. После этого оценки и комментарии можно выгрузить в CSV или XLSX.

Шкала настраивается под конкретное ДЗ, в том числе отдельно для подпунктов. В записанной демонстрации у первого задания два подпункта по 5 баллов, у остальных трёх — по 10. Максимум — 40, без БДЗ.

## Что делает сам агент

Следующий шаг выбирает языковая модель. Она получает результат инструмента и решает, что нужно сделать дальше: прочитать другую страницу, увеличить фрагмент, сверить часть решения с критериями или подготовить оценку.

Например, если фрагмент работы плохо читается, агент может запросить его увеличение и вернуться к проверке после повторного просмотра. Если прочитать его всё равно не удаётся, предусмотрен запрос ручной проверки.

Перед сохранением приложение проверяет, что разобраны все обязательные задания и подпункты, баллы укладываются в заданную шкалу, а у оценок есть обоснования и ссылки на страницы. Если чего-то не хватает, агент получает замечание и может исправить черновик. Общую сумму считает сервер.

Преподаватель сверяет выводы агента и предложенные баллы с работой перед утверждением. GradeAI не выставляет оценки в Classroom или официальную ведомость.

## Запуск

Нужны Python 3.11 или новее, Git и macOS либо Linux.

```bash
git clone https://github.com/Scesss/raif_qual.git
cd raif_qual/3.1

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r requirements-pdf.txt

python scripts/demo.py
```

Откройте http://127.0.0.1:8766. Появится учебный курс с одним ДЗ и тремя примерами работ: правильной, с ошибкой и с нечитаемым фрагментом. Для генерации этих PDF нужен Arial Unicode или DejaVu Sans. Если шрифт не найден, установите DejaVu Sans либо задайте путь к TTF через переменную `REVIEWER_DEMO_FONT`.

Чтобы агент начал настоящую проверку:

1. Откройте вкладку **«Агент»**, выберите **«Подписка ChatGPT»** и нажмите **Continue with ChatGPT**.
2. Завершите вход и разрешите использование подписки, если этот вариант доступен аккаунту.
3. Нажмите **«Получить список»**, выберите доступную модель и сохраните настройку.
4. Нажмите **«Проверить подключение»**. Приложение проверит чтение изображения, вызов инструмента и использование его результата.
5. Перейдите в **«Работы»**, отметьте нужные строки и нажмите **«Проверить выбранные»**.

В демобазе также есть сценарный режим без LLM для проверки интерфейса. Для демонстрации самостоятельной работы агента используйте подключённую модель.

Для своего курса остановите демосервер через `Ctrl+C` и запустите обычное приложение:

```bash
python app.py
```

Откройте http://127.0.0.1:8765. Добавьте студентов во вкладке **«Студенты»**, создайте ДЗ, настройте подключение модели и импортируйте папку с PDF через вкладку **«Работы»**. Пути к материалам указываются для компьютера, на котором запущен сервер. Критерии и перечень заданий обязательны, эталонное решение — по желанию.

Отдельный платный API подключается через переменную окружения `OPENAI_API_KEY` и явный выбор режима **«OpenAI API · отдельная оплата»** в интерфейсе. Автоматического перехода с подписки на платный API нет. Файл `.env` автоматически не загружается.

## Техническая часть

Бэкенд написан на Python: встроенный HTTP-сервер, SQLite для данных и фоновой очереди. Фронтенд — HTML, CSS и JavaScript без отдельной сборки.

Цикл работы: запрос модели → выбранный инструмент → результат инструмента → следующий запрос модели. Для обращения к модели используется `ModelGateway` и потоковый Responses API.

Основные файлы:

| Файл | За что отвечает |
| --- | --- |
| `app.py`, `agent_http.py` | Веб-сервер, API, импорт, запуск и остановка проверок |
| `review_agent.py` | Фоновая очередь и цикл работы агента |
| `agent_tools.py` | Чтение материалов ДЗ, просмотр страниц и увеличенных фрагментов, передача черновика валидатору |
| `model_gateway.py` | Авторизация, подключение модели, потоковые ответы и повторы при сетевых сбоях |
| `review_storage.py` | Проверка оценок, версии черновиков и защита от перезаписи устаревшим запуском |
| `static/` | Веб-интерфейс |
| `demo/`, `scripts/demo.py` | Учебные PDF и подготовка демонстрационного курса |
| `tests/` | Автоматические тесты |

Модель получает доступ к материалам текущей работы через инструменты. Выполнение команд и утверждение оценок ей не предоставлены. Результат привязывается к хешам исходных файлов; черновики сохраняются с историей версий.

Локальные данные хранятся в `data/`, подключения аккаунтов — отдельно, в `~/.config/homework-reviewer/`. База, импортированные работы и токены в репозиторий не включены.

### Тесты

```bash
python -m unittest discover -s tests -v
```

На момент подготовки проекта проходят 49 тестов. Они проверяют инструменты, валидацию, очередь, отмену, обработку сетевых ошибок и сохранность результатов. Тесты не обращаются к настоящей модели и не измеряют точность проверки содержания ДЗ.

Два теста отдельного скрипта сборки PDF требуют Poppler (`brew install poppler` на macOS или `sudo apt install poppler-utils` на Ubuntu/Debian). Без него они пропускаются. Сам агент читает PDF через PyMuPDF и от Poppler не зависит.
