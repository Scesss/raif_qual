# Локальные данные

Эта папка создаётся приложением автоматически. В ней хранятся SQLite-база,
скачанные работы, материалы курса и экспорты. Всё содержимое, кроме этого
файла, исключено из Git: в нём могут быть ФИО, email, решения и персональные
заметки преподавателя.

Перед передачей проекта другому преподавателю не копируйте `data/` в репозиторий.
Для переноса уже накопленной работы используйте отдельную зашифрованную копию
папки и передавайте её только доверенному человеку.
